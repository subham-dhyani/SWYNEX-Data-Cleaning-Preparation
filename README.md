# SWYNEX Data Cleaning and Preparation

## Project Overview
This project focuses on cleaning and preparing a public Bank Marketing dataset using MySQL.

## Dataset
Source: [UCI Bank Marketing Dataset](https://archive.ics.uci.edu/dataset/222/bank+marketing)

## Work Performed
- Identified duplicate records.
- Removed exact duplicate records.
- Checked for missing SQL NULL values.
- Identified and reviewed unknown category values.
- Validated categorical values.
- Checked numerical values for invalid ranges.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Results
The cleaned table contains 45,211 unique records, reduced from 45,962 imported rows.

## Learning Outcomes
Practised SQL queries, duplicate detection, data validation, and data preparation for analysis.
